# 铁大 AI Lab 协会官网

石家庄铁道大学 AI.Lab 协会的静态网站，介绍社团、入社登记和 GitHub 开源组织 Ironseed Lab。

本地预览可在仓库目录运行 `python -m http.server 8000`，然后打开 `http://localhost:8000`。页面由 HTML、CSS、SVG 和 WebP 构成，无构建依赖。

向官网提交修正或建议，可以通过本仓库的 Issue 和 Pull Request。想加入 Ironseed Lab，可在协会群联系组织管理员，提供 GitHub 用户名和想参与的方向。

Vercel CLI 生产部署命令为 `vercel deploy --prod`。
